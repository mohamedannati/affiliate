# Brand assets

Original AI-generated artwork used by the Affiliate app.

| File | Use | Size |
| --- | --- | --- |
| `appicon.png` | App icon (1024×1024) | 1024×1024 |
| `logo.png` | In-app logo (header / profile / launch) | 1408×768 |
| `chicken.png` | Chicken mascot (home hero + game) | 1408×768 |
| `hero.png` | Wide hero illustration | 1584×672 |

These files are also wired into `Affiliate/Assets.xcassets` so they compile into the app automatically. The `design/` folder holds the same images at their original paths.
